# Ambush
*Source: Player's Handbook (2024) p. 94*  

When you make a Dexterity ([[Rules/Source/skills#Stealth\|Stealth]]) check or an [[Rules/Source/variant-rules/initiative-xphb\|Initiative]] roll, you can expend one Superiority Die and add the die to the roll, unless you have the [[Rules/Source/conditions#Incapacitated\|Incapacitated]] condition.
