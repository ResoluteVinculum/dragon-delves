# Tactical Assessment
*Source: Player's Handbook (2024) p. 95*  

When you make an Intelligence ([[Rules/Source/skills#History\|History]] or [[Rules/Source/skills#Investigation\|Investigation]]) check or a Wisdom ([[Rules/Source/skills#Insight\|Insight]]) check, you can expend one Superiority Die and add that die to the ability check.
