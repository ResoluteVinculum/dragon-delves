# Devil's Sight
*Source: Player's Handbook (2024) p. 155. Available in the <span title='Systems Reference Document (5.2)'>SRD</span>*  

**Prerequisite**: Level 2

You can see normally in [[Rules/Source/variant-rules/dim-light-xphb\|Dim Light]] and [[Rules/Source/variant-rules/darkness-xphb\|Darkness]]—both magical and nonmagical—within 120 feet of yourself.
