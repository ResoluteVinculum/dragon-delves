# One with Shadows
*Source: Player's Handbook (2024) p. 156. Available in the <span title='Systems Reference Document (5.2)'>SRD</span>*  

**Prerequisite**: Level 5

While you're in an area of [[Rules/Source/variant-rules/dim-light-xphb\|Dim Light]] or [[Rules/Source/variant-rules/darkness-xphb\|Darkness]], you can cast [[Rules/Source/spells/invisibility-xphb\|Invisibility]] on yourself without expending a spell slot.
