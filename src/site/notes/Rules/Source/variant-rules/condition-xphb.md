# Condition
*Source: Player's Handbook (2024) p. 363. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)* 

A condition is a temporary game state. The definition of a condition says how it affects its recipient, and various rules define how to end a condition. This glossary defines these conditions:

- [[Rules/Source/conditions#Blinded\|Blinded]]  
- [[Rules/Source/conditions#Charmed\|Charmed]]  
- [[Rules/Source/conditions#Deafened\|Deafened]]  
- [[Rules/Source/conditions#Exhaustion\|Exhaustion]]  
- [[Rules/Source/conditions#Frightened\|Frightened]]  
- [[Rules/Source/conditions#Grappled\|Grappled]]  
- [[Rules/Source/conditions#Incapacitated\|Incapacitated]]  
- [[Rules/Source/conditions#Invisible\|Invisible]]  
- [[Rules/Source/conditions#Paralyzed\|Paralyzed]]  
- [[Rules/Source/conditions#Petrified\|Petrified]]  
- [[Rules/Source/conditions#Poisoned\|Poisoned]]  
- [[Rules/Source/conditions#Prone\|Prone]]  
- [[Rules/Source/conditions#Restrained\|Restrained]]  
- [[Rules/Source/conditions#Stunned\|Stunned]]  
- [[Rules/Source/conditions#Unconscious\|Unconscious]]  

A condition doesn't stack with itself; a recipient either has a condition or doesn't. The [[Rules/Source/conditions#Exhaustion\|Exhaustion]] condition is an exception to that rule.
