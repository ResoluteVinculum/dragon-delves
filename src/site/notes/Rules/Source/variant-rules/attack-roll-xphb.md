# Attack Roll
*Source: Player's Handbook (2024) p. 361. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)* 

An attack roll is a [[Rules/Source/variant-rules/d20-test-xphb\|D20 Test]] that represents making an attack with a weapon, an [[Rules/Source/variant-rules/unarmed-strike-xphb\|Unarmed Strike]], or a spell.
