# Death Saving Throw
*Source: Player's Handbook (2024) p. 365. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)* 

A [[Rules/Source/variant-rules/player-character-xphb\|player character]] must make a Death Saving Throw (also called a Death Save) if they start their turn with 0 [[Rules/Source/variant-rules/hit-points-xphb\|Hit Points]].
