# Stable
*Source: Player's Handbook (2024) p. 374. Available in the <span title='Systems Reference Document (5.2)'>SRD</span> and the Free Rules (2024)* 

A creature is Stable if it has 0 [[Rules/Source/variant-rules/hit-points-xphb\|Hit Points]] but isn't required to make [[Rules/Source/variant-rules/death-saving-throw-xphb\|Death Saving Throws]].
