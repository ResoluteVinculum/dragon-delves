# Magic Item Tools
*Source: Dungeon Master's Guide (2024) p. 220* 

**Magic Item Tools**

| Item Category | Required Tool |

| Potion | [[Rules/Source/items/alchemists-supplies-xphb\|Alchemist's Supplies]] or [[Rules/Source/items/herbalism-kit-xphb\|Herbalism Kit]] |

| Rod | [[Rules/Source/items/woodcarvers-tools-xphb\|Woodcarver's Tools]] |
| Scroll | [[Rules/Source/items/calligraphers-supplies-xphb\|Calligrapher's Supplies]] |
| Staff | [[Rules/Source/items/woodcarvers-tools-xphb\|Woodcarver's Tools]] |
| Wand | [[Rules/Source/items/woodcarvers-tools-xphb\|Woodcarver's Tools]] |
| Weapon | [[Rules/Source/items/leatherworkers-tools-xphb\|Leatherworker's Tools]], [[Rules/Source/items/smiths-tools-xphb\|Smith's Tools]], or [[Rules/Source/items/woodcarvers-tools-xphb\|Woodcarver's Tools]] depending on the kind of weapon as noted in the tools' descriptions |
