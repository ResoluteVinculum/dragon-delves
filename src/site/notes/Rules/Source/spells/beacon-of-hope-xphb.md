# Beacon of Hope
*3rd-level, Abjuration*  


- **Casting time:** 1 Action
- **Range:** 30 feet
- **Components:** V, S
- **Duration:** Concentration, up to 1 minute

Choose any number of creatures within range. For the duration, each target has [[Rules/Source/variant-rules/advantage-xphb\|Advantage]] on Wisdom saving throws and [[Rules/Source/variant-rules/death-saving-throw-xphb\|Death Saving Throws]] and regains the maximum number of [[Rules/Source/variant-rules/hit-points-xphb\|Hit Points]] possible from any healing.
